# 跨行业编排方法

固定的是画面组织和运动语法，变化的是证据、文案、图表和讲述目的。

|讲述内容|适合的组件|编辑约束|
|---|---|---|
|开场问题或主题|hook、quote|一句主张，不先堆产品名和无关装饰|
|过程与步骤|steps、timeline、bullets|每项随关键词进入，步骤数来自原文|
|两个或三个对象比较|comparison、cards|对比维度一致，不补造优劣结论|
|真实成果或数字|metric、curve|需要可追溯的数字与单位；仅原理示意时明确标注|
|工具或操作讲解|chat、file、code、player|概念演示与真实界面区别；真实 UI 必须有资产|
|产品、地点、过程证据|media、triptych、collection|素材与口播对应，三联素材各不相同|
|抽象关系或阶段演变|orbit、curve、styles|图形承载关系，不能把无意义装饰当证据|
|情绪与提醒|quote、stamp、interaction|强调关键语义，避免每段同一特效|
|章节或收束|gallery、end|章节才导航，结尾稳定留阅读时间|

教育可用例题、推导、操作录屏；餐饮可用原料、制作、成品实拍；制造可用部件、工序、检测记录；软件产品可用界面、功能流程、真实录屏。这些只是映射示例，不自动加入新片。

## 分镜笔记

每镜记录：口播起止 → 核心意思 → 观众需要看到什么 → 素材来源 → 布局与人物角色 → 标题/主容器/证据/注释各自出场点 → 字幕 → 前后衔接。

同一素材不足时，优先让该段保持讲述与清楚的文字图解，不编造实拍或截图。镜头变化应来自语义变化。全片检查不同场景的比例，不能把所有内容压成三张卡片；也不要为了凑足组件种类加入无意义镜头。

## 画中画

大竖窗承担主要讲述；圆头像给信息图或录屏让位；中心头像用于互动；三联证据段主讲窗退出。改变位置时检查移动路径而不只看终点。人物窗口中的脸和手势要清楚，裁切框跟着源素材特点调整。左右大窗与顶角头像均需检查字幕和标题的安全区。

## 内容事实与示例

examples 下的计划仅是排版/字段演示，含“示例”“演示”的数据不能用于发布。每次新片从原文建立事实表：名字、数字、时间、单位、产品名、限定词。只有对应素材明确支持才进入成片。参考片的宣传文案也不是新片事实。
